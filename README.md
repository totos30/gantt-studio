## 🇫🇷 Gantt Studio

> Un outil de planification de projet élégant, 100% autonome, sans installation ni serveur.

**Gantt Studio** est une application web single-file permettant de créer des diagrammes de Gantt et des Roadmaps interactifs directement dans votre navigateur. Aucune dépendance, aucune installation, aucune donnée envoyée sur un serveur.

### ✨ Fonctionnalités

- 📊 **Diagramme de Gantt interactif** — glisser-déposer des barres, redimensionnement, sélection
- 🗺 **Vue Roadmap** — regroupement des tâches par initiative avec calcul automatique du statut
- 🎯 **Jalons** — avec couleur personnalisable et statut atteint / non atteint
- 🎨 **Couleurs personnalisables** — par tâche, par jalon, par groupe
- 👤 **Affichage du responsable** — optionnel, paramétrable
- 📥 **Import Excel / CSV** — avec groupes et couleurs
- 📤 **Export SVG, PNG, CSV, Excel** — haute résolution
- 🖼 **Export Slide** — formats 16:9, 4:3, A4 paysage
- 🌐 **Bilingue FR / EN**
- 🔲 **Mode plein écran** — masquage de la sidebar
- 💾 **100% offline** — aucune dépendance externe

### 🚀 Utilisation

**Option 1 — En ligne (GitHub Pages)**

[gantt-studio](https://totos30.github.io/gantt-studio/gantt-studio.html)


**Option 2 — En local**
1. Télécharger `gantt-studio.html`
2. Ouvrir dans votre navigateur
3. C'est tout.


### 🛠 Format d'import CSV

| Colonne | Contenu | Exemple |
|---|---|---|
| A | Nom de la tâche | Développement backend |

| C | Date de fin | 31/03/2025 |

## 🇬🇧 Gantt Studio

> An elegant, fully self-contained project planning tool — no install, no server, no account.

**Gantt Studio** is a single-file web application for creating interactive Gantt charts and Roadmaps directly in your browser. No dependencies, no installation, no data sent to any server.

### ✨ Features

- 📊 **Interactive Gantt chart** — drag & drop bars, resize, select
- 🗺 **Roadmap view** — group tasks by initiative with automatic status computation
- 🎯 **Milestones** — with custom color and reached / not reached status
- 🎨 **Custom colors** — per task, per milestone, per group
- 👤 **Owner display** — optional, configurable in settings
- 📥 **Excel / CSV import** — including groups and colors
- 📤 **SVG, PNG, CSV, Excel export** — high resolution
- 🖼 **Slide export** — 16:9, 4:3, A4 landscape formats
- 🌐 **Bilingual FR / EN**
- 🔲 **Full screen mode** — sidebar toggle
- 💾 **100% offline** — no external dependency

### 🚀 Usage

**Option 1 — Online (GitHub Pages)**

[gantt-studio](https://totos30.github.io/gantt-studio/gantt-studio.html)


**Option 2 — Local**
1. Download `gantt-studio.html`
2. Open it in your browser
3. That's it.


### 🛠 CSV Import Format

| Column | Content | Example |
|---|---|---|
| A | Task name | Backend development |
| B | Start date | 01/01/2025 |
| C | End date | 31/03/2025 |
| D | Progress % | 45 |
| E | Type | Tâche / Jalon |
| F | Owner | Etienne |
| G | Color (hex) | #3b82f6 |
| H | Group / Initiative | Sprint 1 |
| I | Group color (hex) | #8b5cf6 |

> 💡 Download the CSV template directly from the application.
